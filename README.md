# Умножайка

Небольшое installable PWA для самостоятельной тренировки таблицы умножения 1–10.

## Локальный запуск

Требуется Node.js 20+ и Python 3.

```bash
npm test
npm run serve
```

Откройте `http://localhost:4173`.

## iPhone / iPad

1. Разместите папку на любом статическом HTTPS-hosting.
2. Откройте адрес в Safari.
3. Нажмите «Поделиться» → «На экран “Домой”» → «Добавить».

На локальном компьютере iPhone должен открывать HTTPS-адрес хостинга; `localhost` компьютера с телефона недоступен без дополнительной настройки сети.

## Хранение данных

Прогресс хранится только в браузере (`localStorage`, ключ `umnozhayka.progress.v1`). Он не отправляется на сервер. Очистка данных Safari или удаление данных сайта удалит прогресс.

## Hosting

Приложению не нужны backend, база данных или сборка. Достаточно статически опубликовать содержимое репозитория с HTTPS и корректными MIME types для `.webmanifest` и `.js`.
