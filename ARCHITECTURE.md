# Architecture

## Решение
Статическое PWA без runtime-зависимостей:

- `index.html` — семантическая разметка и PWA metadata;
- `styles.css` — mobile-first адаптивный детский UI;
- `src/core.js` — чистая доменная логика и безопасная нормализация прогресса;
- `src/app.js` — DOM, keyboard flow, localStorage и UI state;
- `manifest.webmanifest`, `service-worker.js`, `assets/` — установка и offline shell;
- Node built-in test runner — unit tests без test framework dependency.

## Состояние
Накопленный прогресс хранится в `localStorage` под версионированным ключом. Текущий пример и временная обратная связь не считаются накопленным прогрессом. Повреждённые/устаревшие данные нормализуются к безопасным значениям.

## Smart practice
Локально учитываются ошибки по нормализованной паре (например, 7×8 и 8×7 — одна пара). При генерации следующего примера ошибки добавляют небольшой вес, но базовый шанс остаётся у всех 100 комбинаций.

## Риски и защита
- повторный Enter не должен повторно начислять звезду — состояние ответа блокирует повторную проверку;
- localStorage может быть недоступен/повреждён — чтение и запись защищены;
- service worker обновляет shell по версии cache;
- системное `prefers-reduced-motion` отключает необязательные анимации.
